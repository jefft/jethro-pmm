### Verification required to edit in the members area

Editing family details in the members area now requires a verification code
sent by SMS to the mobile number on the member's account. Editing is refused
(or a clear error is shown) when the account has no mobile number or the SMS
gateway is unavailable; a system administrator can change the number. Codes
expire after ten minutes, can be requested once a minute, and allow five
attempts. A successful save ends the verification, so the next edit needs a
fresh code.

Until a member has verified, email addresses and mobile numbers shown in the
members area are masked, and mobile numbers can no longer be changed there at
all — only through the control centre. Members can still log in without a
code, so emailed account recovery continues to work.
